## Implemented contract

`ControlMvpReadCache` is an opaque cloneable handle. Constructors enable default caches, clones share ownership, and independent reopenings start empty. Explicit configuration, compatible-handle attachment, statistics, and disabling are available without changing the public transaction trait. An unfundable nonzero cache configuration returns validation failure; zero capacity selects the direct path.

The handle retains the backend identity and scope. Full owning references, versions, supported formats, and validation context identify entries; durable maintenance has an explicit independent authority namespace. Every substitution performs a fresh object HEAD. Admission brackets authenticated loading with agreeing HEAD observations. Missing, changed, unusable, or failed version observations use existing direct behavior.

The metadata pool admits authenticated directories, unhydrated transaction metadata, and complete-segment certificates. The decoded pool retains owned validated rows. A certificate is issued only after the complete original segment validation and is usable only while every certified block is resident under the same proof. Hydration, replay, ordering, uniqueness, history/state checks, and all mutable authority reads remain authoritative on each operation.

| Bound | Frozen value |
| --- | ---: |
| Metadata pool | 32 MiB |
| Decoded pool | 128 MiB |
| Final entry charge, either pool | 8 MiB |
| Single metadata reservation | 16 MiB |
| Aggregate in-flight reservations | 64 MiB |
| Cache-owned loads | 8 |
| Live metadata / decoded records | 1,024 / 4,096 |
| Participants per load / aggregate | 32 / 256 |
| Minimum record / participant bookkeeping | 4 KiB / 512 B |
| Active-handle administration | 8 KiB plus owned identity |
| Nonempty allocation allowance | 64 B |

FIFO eviction has no TTL. Reservations, resident entries, and leased evicted or residency-declined results remain charged until their final owner drops. Shared keys own one allocation charge. Weak in-flight Shared futures introduce no detached task. Admission and cleanup ownership exist before the returned future is first polled; cancellation of the final participant drops the load. Unsupported or exhausted admission uses a counted uncached fallback. The contract bounds cache ownership, not request-owned copies, decoder scratch, backend buffers, uncached concurrency, or process RSS.
