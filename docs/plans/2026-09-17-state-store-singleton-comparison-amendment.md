# Singleton comparison amendment

Frozen before Emit and mixed data implementation, 2026-09-17. This amends the Step 3 contract; it is not qualification evidence. Existing wire fields and phase names remain unchanged.

Read a standard block first when decoding is required to resolve overlap with an oversized singleton. Complete standard prefixes before the pending key and record the selected row's actual block ordinal. Every boundary reread is charged. Fully consumed floor leaves require exact endpoint and descriptor/index authentication; partial standard boundaries require decoding. Final verification independently checks exclusions.

`CompareSource -> CompareCurrent` may fill either missing value witness. Every existing witness remains unchanged. `CompareCurrent -> Emit` freezes both witnesses. Both witnesses may be empty only in `CompareSource`, and only when independent receipt verification proves standard-block exclusion of the pending key. All later Pending states require a value witness.

`Complete` may be consumed by a standard receipt or directly by the next singleton comparison. After the last key an exhaustion receipt must prove both pinned roots complete. Native advancement remains disabled.
