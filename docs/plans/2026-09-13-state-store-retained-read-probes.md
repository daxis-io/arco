# Step 3 amendment 2: bounded immutable range probes

This narrow amendment replaces the retained-source amendment's fixed descriptor 4 MiB+1 probe with exact-sized bounded probes, while preserving the 4 MiB encoded cap, 8 MiB aggregate range-probe budget, 16 read-object ceiling and 4096 storage-operation ceiling. It is recorded before affected successful measurements. The prior wording made ordinary manifest/transaction/descriptor combinations unnecessarily inadmissible when each probe reserved its maximum.

A retained descriptor uses the authenticated selected singleton leaf length L: require 1 <= L <= 4 MiB and reserve L+1 before GET range [0,L+1). Require returned length exactly L, exact raw SHA-256 equal the leaf/path commitment, canonical bytes, and all cross-bindings. A HEAD may be used as additional evidence but cannot override the authenticated L. A manifest or artifact whose authenticated reference commits only its raw SHA-256 may use an initial HEAD-admitted L: require 1 <= L <= its existing encoded cap before allocating/reserving L+1, then GET [0,L+1), require returned length exactly L and validate the exact committed raw digest. The extra byte is mandatory: a raced append preserving the old prefix must fail. Missing/oversized/inconsistent evidence fails closed. No error, cancellation or successful read refunds a charged probe.

Mutable catalog/retained pointers keep fixed 64 KiB+1 probes, at most four attempts, equal nonempty metadata-before/after versions and exact sizes. Include catalog HEAD lookup attempted before historical fallback in the retained subbudget. A current-HEAD fast path must bind the authenticated source manifest and validate pointer writer/reclamation fences against that manifest; metadata stability alone is insufficient. Each HEAD, GET, PUT and CAS counts toward the per-invocation operation ceiling, including failures and admission rejection after metadata. The 16-object cap counts each object GET probe, including retry probes; metadata HEADs are separately counted operations, never omitted from accounting. Directory lookup reserves at most eight actual page-length+1 probes, with each page <=64 KiB; a conservative upfront eight*(64 KiB+1) reservation is valid.

Before accepting the final read result, all manifest, transaction, transition, projection-source and synthetic-genesis witness reads must pass through the same retained budget. Reuse authenticated manifest bytes; do not evade admission by delegated reads or by constructing a reader that validates additional evidence outside the measured boundary. Per-read raw bytes, canonical encode/decode scratch and owned record capacity remain subject to the standard ownership bound.

Required regressions: append object bytes during metadata/range interval; wrong/zero/oversized metadata length; object missing after HEAD; exact-length wrong digest; pointer change/delete before/after bounded GET; current pointer fences below authenticated manifest; repeated unstable pointer exhausting read budget; a transaction manifest whose indirect artifact reads exhaust aggregate admission. Test stable valid current and selected historical references under the full counter inventory.
