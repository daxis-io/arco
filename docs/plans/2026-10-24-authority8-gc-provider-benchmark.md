# Opt-in authority-8 GC provider benchmark packet

Status: prepared for separate authorization; not executed. No provider claim follows from MemoryBackend or this packet. The existing Gate-7 provider harness is not qualified for authority-8 GC merely because it exists.

Use a disposable, versioned **general-purpose S3 bucket**, one region, one tenant/workspace/domain prefix and an exact source/executable/fixture manifest. Directory buckets and R2 have different listing/version semantics and are out of this packet. Do not benchmark against an operator's existing namespace. Deny DELETE and mutable-authority writes in the measured phase at both wrapper and IAM boundaries.

The approval packet must fill account, role, bucket, region, disposable tenant/workspace, expiry, source-manifest SHA, executable SHA, fixture/oracle SHA, expected root/HEAD identities and the immutable result directory. Validate those values offline before credentials are loaded. Reuse the current `S3StorageBackend::for_qualification` and manifest/journal/namespace/reservation controls in `crates/arco-storage-s3/src/bin/qualification/provider.rs`; its historical BASE/phase guard must be updated explicitly for the approved source, not bypassed. Never run the existing `provider` command and call its unrelated scenarios this benchmark.

Execute these separately metered phases after approval:

1. **Fixture preload**, only if no exact imported fixture exists: unchanged 2,419,200 retained / 1,048,576 target / 65,536 outbox axes. Max 2,000,000 transport attempts, 4 GiB submitted bytes, 90 minutes. Retain the exact object/version/content manifest and all partial outputs. This is setup, excluded from planner cost but reported and paid separately.
2. **Cold one-page GC planning**, including fresh seed/schedules and independent verification. Max 300,000 transport attempts, 256 MiB metadata bodies, 256 KiB proof-write attempts, 128 KiB final proof, 30 minutes. No Arrow payload GET, mutable HEAD CAS, or DELETE. Compare exact orphan candidates with the retained oracle.
3. **Complete sweep**, cold independent session, both inventory prefixes. Max 500,000 transport attempts, 512 MiB metadata bodies, same proof ceilings, 30 minutes. Keep per-invocation 4,096-operation/64-MiB invoices. Every additional inventory page records zero graph metadata reads and <=512 logical calls for the frozen scope.
4. **Recovery**, fresh process after partial traversal and after complete traversal; two repetitions. Max 300,000 transport attempts and 256 MiB metadata per repetition, 30 minutes each. Rebuild opaque membership once per process. A persisted completion receipt must not replace the graph walk.

A successful nonempty bounded range now performs one native GET. Failed ranges can require a fallback HEAD to preserve empty/EOF semantics. Reserve all allowed GET and fallback-HEAD attempts before sending; successful-path savings do not waive worst-case admission. The qualification adapter allows one retry for ordinary requests and none for conditional writes. Capture actual method/path/status/bytes/attempt timings below the SDK, including credential and LIST requests, using the existing controlled proxy/journal pattern. Account for LIST overfetch (up to 1,000 provider rows vs 256 admitted Arco rows). Verify proxy/SDK settings using local loopback faults before a provider run. Adapter-call counts are not transport-attempt counts.

Abort before sending on scope drift, request/byte/time/cost exhaustion, changed root/HEAD/pin selector/epoch, missing/corrupt proof, unavailable storage, unknown metadata ownership, any invoice backpressure, or any attempt at data payload read, authority CAS or DELETE. A failed or expired seed never releases a protected root. Reserve in-flight attempts and bytes so concurrency cannot overshoot the cap. Record SDK retries separately from application restart/replayed-unit work.

Keep default proof admission at 30 minutes. The deterministic 25-ms serial-request model may exceed this deadline even after a 10x logical-call reduction; that is a failed latency gate, not a reason to extend root validity. Regional provider latency and bounded concurrency require their own measured gate.

**Cleanup:** no automatic cleanup. Preserve source, object/version manifest, proofs, errors and journals. A separate exact-prefix cleanup authorization must name all generated object versions and be preceded by a fresh active-writer/open-request check. Partial preload or aborted runs remain retained. No benchmark can enable authority-8 active deletion, maintenance, public routing or production.

The GC planner is connected to the existing supervisor through a dedicated `gc-rehearsal` entry point restricted to numeric loopback and dummy credentials. Its killed-process recovery and fault rehearsal measure actual local HTTP attempts. The real-provider validation path still rejects GC packets. Before authorization, implement and locally qualify an explicit versioned-S3 GC packet for the exact approved source, including conservative request reservations and all artifact identities. This specification does not make the historical provider command or the loopback-only command runnable against S3.
