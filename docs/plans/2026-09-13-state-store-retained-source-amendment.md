# Step 3 amendment 1: selected retained-source authority (revision 3)

This amendment supersedes revision 3 assumptions about an existing global retained-root anchor. The retention mutation epoch is an exclusion/fencing record, not membership authority. The compiled forged-attachment regression is retained. Exact-current-HEAD persistence/resolution is the initial read-only foundation; no immutable standalone attachment authenticates a detached candidate.

Synthetic authority 8 gains an explicit selected retained-read index. It cannot select an ordinary mutation base or replace the single catalog HEAD. Production authority 7, restore-plan 6, and PersistedAuthorityReference wire bytes remain unchanged. Checkpoint, export, conversion, reclamation and maintenance remain unsupported for authority 8 in this slice.

## Exact records and role isolation

The pointer record type is `arco.retained-source.pointer`, version 1. The descriptor record type is `arco.retained-source.descriptor`, version 1. Both use deterministic fixed-field serde JSON, deny unknown fields, and require decode/reencode equality to exact raw bytes. Required fields have no omitted/default alternative encoding. Digests are lowercase 64-character SHA-256 hex. The descriptor content binds exact canonical reference bytes, `reference_raw_sha256` (SHA-256 of those bytes), scope, implementation and authority format, configured nonsecret DurableAuthorityBinding, canonical source manifest path/ID/raw SHA-256/logical sequence, exact original deadline, capture operation ID, and positive capture epoch. Repeated fields must agree with the authenticated reference and manifest. `descriptor_raw_sha256` means SHA-256 of exact descriptor bytes; its content-addressed path and selected leaf commit it. This digest is not inside the descriptor. Snapshot raw digest is a separate witness and is not included in a descriptor that the snapshot may list as a required object. No self-hash cycle is allowed.

The 32-byte reference key is SHA-256 of the literal bytes `arco.retained-reference.key.v1\0`, followed by a u64 big-endian canonical-reference byte length, followed by those exact bytes. Different deadlines produce different keys. Directory leaves must have first == last == requested key, rows == 1, bytes in 1..=4 MiB, and exact descriptor digest/path/length. Directory lookup returns only a candidate; predecessor, covering interval, gap or multirow leaf never proves membership. Validate the leaf before descriptor or source reads.

Reuse directory-v1 wire encoding through a separate internal retained constructor. Its scope hash includes literal `arco.directory.role.retained-reference.v1\0` before the existing tenant/workspace/domain encoding. Its prefix is exactly `control/v1/domains/<domain>/retained/v1/directory`, with `{keys,pages}/<digest>` children. Root/page/key encoding, decoding, hashing, lookup, build, update and independent path-copy verification all use this role. Ordinary Directory::new bytes and paths remain unchanged. The retained wrapper must never decode using the ordinary constructor. Cross-role roots and substituted pages fail before descriptor reads.

## Capture publication and exact reconciliation

A private invocation-local capture context carries the held existing global retention lock, exact owned mutation epoch, stable capture operation identity and authenticated capture timestamp. Public persist_state_reference is read-only and cannot select membership. Authenticate current HEAD or existing bounded authenticated ancestry/private source proof before minting. A historical retained entry alone cannot authorize a new deadline.

Publication order is mandatory: stage immutable descriptor and role-specific independently verified path-copy pages; encode and publish/reconcile the immutable workspace snapshot; select/reconcile its initial pin; re-fence the held epoch; perform one exact conditional retained-pointer publication. Use the existing workspace journal and retention coordination, not another journal. The pointer binds scope, configured binding, type/version, exact directory root, last_operation_id, previous generation and root digest, new generation and root digest, and exact capture epoch. Genesis previous generation is zero with no previous root; successors increment with checked arithmetic and bind the authenticated predecessor. The selected root is the retained-read trust anchor; unselected pages, descriptors and snapshots cannot mint authority.

An exact preexisting entry is idempotent only when authenticated before this invocation and requires zero selector writes. Immutable path conflicts are idempotent only for exact bytes. Same-key/different-descriptor conflicts fail closed. Direct selector PreconditionFailed succeeds only after stable exact expected-pointer readback, or the preexisting no-write case; otherwise it fails without recomputing against a foreign root in the same invocation. Following a possibly sent CAS, settlement requires stable equality to the complete expected pointer bytes and selected exact membership. Mere membership in another pointer is not proof of this operation's commitment. Cancellation, absent evidence, a different pointer, or exhausted budgets leaves the epoch in flight/unresolved. A later invocation may recompute only after explicit reconciliation/settlement of the prior epoch. Do not repeat a possibly sent CAS on restart.

## Lifetime and fences

Membership is independent V8 read authority until the exact reference deadline. Workspace pin release blocks starting/resuming workspace restore through source-pin preflight, but does not revoke an already protected retained member/token. Step 4 must trace retained entries, descriptors, directory pages and source objects until deadline and then remove them; Step 3 does no deletion, repacking or deadline extension.

After claiming the capture epoch, obtain fresh capture_authenticated_at. Require capture_authenticated_at < reference.retention_deadline == snapshot.retained_until <= checked_add(capture_authenticated_at, 30 days). The independent authority deadline is exactly reference.retention_deadline. Resolve/plan/advance obtain fresh observed_now and require observed_now < that deadline. Restore work independently requires observed_now < checked_add(original immutable request.requested_at, 24 hours), with future request time rejected. Retries and replacement attempts preserve both original deadlines and exact reference bytes. A new deadline requires newly authenticated current/ancestry/private source authority at that invocation; retained membership alone never extends it.

Capture epoch is positive committed provenance and exact lost-response evidence, not an equality check against future global epochs. Exact epoch ownership/re-fencing is required during capture staging/publication. Historical resolution validates committed shape/digests, without comparing to the current global epoch. Source writer/reclamation fences remain separate authenticated manifest fields.

## Numeric admission and bounded workspace I/O

These limits fit the selected independent-authority resolution and should be frozen before implementation:

- Retained pointer: exactly one mutable object at `control/v1/domains/<domain>/retained/v1/current.json`; encoded size `1..=64 KiB`; at most four stable-read attempts. Each attempt is `HEAD-before`, reserve `64 KiB + 1`, range GET, `HEAD-after`; require equal nonempty versions and `before.size == after.size == bytes.len()`. Exhaustion is ambiguous/fail-closed, never absence.
- Retained descriptor: exact path `control/v1/domains/<domain>/retained/v1/descriptors/<descriptor_raw_sha256>.json`; encoded size `1..=4 MiB`; range probe `4 MiB + 1`; canonical exact bytes and domain-separated raw digest must match the path and selected singleton leaf. Immutable path conflict is idempotent only for exact bytes.
- Retained directory: exact role-specific prefix `control/v1/domains/<domain>/retained/v1/directory`; fanout 128, depth 8, page `1..=64 KiB`; 32-byte reference hashes stay inline, so lookup performs no external key-object read. One resolution permits at most eight page reads. Keep the existing conservative path-copy object ceiling for update/verification, but charge actual pages and immutable writes.
- Retained-resolution sub-budget: at most 16 read objects and 8 MiB of encoded range probes total for pointer, depth-8 directory path, descriptor, and the authority manifest. Reserve before every read and do not refund on error/cancellation. This covers `64 KiB + 8*64 KiB + 4 MiB + 1 MiB` plus probe/margin. The normal current-HEAD fast path may use fewer objects but must obey the same object caps.
- V8 workspace control records: each immutable snapshot, restore request, restore attempt, pin revision, journal, and read manifest is `1..=4 MiB`; each mutable pin selector and retained pointer is `1..=64 KiB`. The V8 configured restore path gets one 32 MiB aggregate encoded-metadata probe budget per public invocation across source preflight, pin-chain verification, request/journal/attempt loading, and retained-resolution reads. The 8 MiB retained-resolution limit is a sub-budget of that 32 MiB, not an additional allowance. Preserve existing V7-only dispatch behavior.
- Pin chain: retain the 1,024 revision count ceiling and add the 32 MiB aggregate byte charge. Walk backward from the stable selected latest selector, verifying each predecessor path/digest/transition while holding only latest, current, previous, and initial decoded summaries. Do not retain/reverse all raw revision byte vectors. Charge one object per selector/revision.
- Owned memory: release raw bytes before proceeding whenever their authenticated digest and the minimal needed decoded summary are retained. The combined V8 control-preflight live-owned ceiling is 64 MiB, matching the standard request-owned ceiling; separately report the maximum raw bytes, decoded records, container capacity, canonical re-encode scratch, and cached immutable bytes. Exceeding any encoded/object/owned limit is backpressure/fail-closed.
- Deadline admission: after the retention epoch is claimed, take one fresh `capture_authenticated_at`. Require `capture_authenticated_at < reference.retention_deadline == snapshot.retained_until <= checked_add(capture_authenticated_at, 30 days)`. The selected independent retained membership remains read authority until that exact reference deadline even if the workspace pin is released. Existing workspace preflight still rejects a released pin, so it cannot start/resume restore from that snapshot. Resolve/plan/advance require fresh `observed_now < reference.retention_deadline`, while restore work also independently requires `observed_now < checked_add(request.requested_at, 24 hours)`; neither retry nor replacement resets either value.
- Cancellation and publication recovery: before retained-selector CAS, cancellation leaves only immutable unselected objects and the in-flight epoch. After a possibly sent CAS, cancellation/drop leaves the epoch in flight. Recovery under the same global lock performs a stable 64 KiB pointer read and settles only if exact expected pointer bytes, operation ID, predecessor generation/root, successor generation/root, and selected singleton membership all agree. Absence, a different pointer, or exhausted read budget remains unresolved. Direct precondition conflict is exact-idempotent success or terminal failure; no same-invocation merge/retry on a foreign selected pointer.


For the descriptor, the raw SHA-256 definition above controls: role separation is supplied by the reference-key preimage, role-specific directory, fixed record type and scoped content-addressed path; do not silently replace raw SHA-256 with a different digest. Every failed probe, retry, metadata request and decode is charged; no refund on cancellation. Actual existing authority-manifest encoded caps remain enforced; the 8 MiB aggregate may reject an individually valid combination before I/O. The illustrative 1 MiB manifest estimate is not permission to underestimate a larger manifest or its scratch.

The V8 workspace budget covers the actual source snapshot/pin preflight and request/attempt/journal/read-manifest reads, not just participant code. Preserve V7-only dispatch. Backward pin verification holds only the latest/current/previous/initial summaries, with per-transition digest/path and state checks; no complete raw chain vector or reverse pass. Combined decoded containers, canonical-reencode scratch and caches are measured separately from encoded probe admission.

## Required behavioral evidence

Compile and observe a behavioral failure before each behavior change. Cover cross-role root/page/update substitution; exact singleton gaps and malformed endpoints/count/length/digest; noncanonical/unknown/repeated-field corruption; forged detached candidate/descriptor; source resolution after more than 32 ordinary advances; warm changed/deleted pointer/page/descriptor; unrelated epochs A then B preserving A; current versus retained-only deadline changes; expiry equality, overflow, future request time; capture then pin release with direct read allowed until deadline and workspace restore denied.

Exercise every capture cut point: before send, send without write, committed send with lost response, response before epoch settlement, cancellation/readback interruption, foreign selector despite epoch, preexisting exact entry, conflicting descriptor. Assert exact selector bytes, zero/one CAS counts and durable epoch states. Oversized snapshot/selector/revision/chain and aggregate probe/owned-memory ceilings must fail before over-allocation. Measure maximum valid pin chain plus depth-eight retained lookup on the actual workspace path. The isolated current-HEAD foundation does not establish durable restore qualification.

This amendment does not transfer prior quantitative evidence to new source. Targeted role/V8 parity, fault and cost lanes are mandatory; a full ordinary 180k matrix is required if shared ordinary directory behavior or V7 workspace behavior changes, not for isolated new-role/V8 helpers.

## Final freeze clarifications

The invocation-local private source proof is nonserializable and minted only by the explicitly configured authority adapter after exact authenticated current-HEAD or bounded authenticated current ancestry validation. It binds exact private token, scope/location, source manifest ID/raw digest/sequence, capture operation and owned epoch. It is an output of that validation, not a third independent authority. Never mint it from a caller-supplied reference, predicted candidate, descriptor, persisted seal, or retained membership alone. It cannot authorize a new deadline after its source/capture invocation expires.

Select the bounded V8/mixed workspace loader from the trusted configured registry before reading or decoding an untrusted snapshot. Do not infer bounded dispatch from fields inside that snapshot. The 32 MiB aggregate applies to all source preflight required-object range probes (including scan_preflight_objects), snapshot/pin/request/attempt/journal/read-manifest and retained-resolution reads. Every HEAD, GET/range GET, immutable PUT and CAS during the public invocation also consumes one of a maximum 4096 storage operations; retries and failures consume budget. Metadata-only HEAD operations charge their actual encoded response ownership; GET probes reserve their encoded cap before I/O. Oversized required provider objects fail bounded V8 preflight before unbounded get_raw; V7-only dispatch retains its behavior. Test an oversized object through scan_preflight_objects and an untrusted snapshot trying to disable bounded dispatch.
